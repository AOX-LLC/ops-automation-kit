aox-logo-black.png is the AOX logo for the light theme and aox-logo-white.png is the same mark for the dark theme: top left, 20px tall, then a divider and the page name. The page shows one of the two by theme, using CSS only. Don't recolor either or their lime dots.

**The AOX logo is a trademark of AOX LLC and is not licensed under this repository's MIT license.** You may not use it to suggest your deployment comes from or is endorsed by AOX. Replace it in your own deployments: put your own logo in this folder (for example `my-logo.png`), set `OPSKIT_BRAND_LOGO_URL` to its path (for example `/static/brand/my-logo.png`), optionally `OPSKIT_BRAND_LOGO_DARK_URL` to a dark-theme variant (without one, your logo shows in both themes; the dark file is only derived for a light logo named `*-black.png`, as `*-white.png`), and `OPSKIT_BRAND_LOGO_ALT` to its alt text, then run `make up` to rebuild the image. To hide the logo, set `OPSKIT_BRAND_LOGO_URL` to empty. The URL must be same-origin: the page's content security policy blocks an external URL.
