aox-logo-black.png is the AOX logo for the light theme, from the design system's Logos group: top left, 20px tall, then a divider and the page name. Don't recolour it or its lime dots. To use another logo, put it here and set OPSKIT_BRAND_LOGO_URL to its path. The URL must be same-origin (for example a path under /static/): the page's content security policy blocks an external URL. An empty value hides the logo.
